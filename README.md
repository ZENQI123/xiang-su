# 像素战记（策略塔防游戏）

> AI 辅助制作

## 游戏介绍

本游戏中你需要通过召唤士兵抵御一波波敌人的进攻，保卫你的基地。

### 游戏玩法

- 每回合结束会获得 10 金币低保，额外金币产出需将矿工移动到矿井
- 金币可在商店中购买升级卡，提升特定兵种的属性
- 通过每回合有限的行动值来召唤士兵或者刷新商店

### 游戏亮点

- 本游戏有多种兵种（根据关卡进度解锁），各自有独特的能力，玩家可以自由搭配，享受自己决策的成就感
- 多种随机事件，增强了该游戏的随机性和趣味性
- 极具挑战的多种怪物设计，十分考验玩家的决策力和执行力
- 即时决策设计，这个考验玩家的想象力，出其不意的决策可能带来巨大的收获
- 图鉴随玩家进度更新，方便玩家调整策略，取得胜利

## 技术栈

- Canvas 2D 全量绘制战斗场景（22×14 网格，56px/格）
- `requestAnimationFrame` 主循环，支持倍速切换
- Web Audio `AudioContext` 实时合成音效（无音频文件），含 BOSS BGM
- `localStorage` 存档：进度、图鉴、静音、倍速、中途战斗存档
- A\* 寻路、地形 / 寻敌 / 事件系统全部自研
